# 前端设计

- 一句话方向：窄导航、宽工作区、小字号、浅灰到白的三级底色、颜色只用来识别——安静的工作台，数字和状态一眼可读。
- 设计来源：一份任务看板截图的设计提炼（Linear 一类工具的做法）。下文标 **提炼** 的是提炼里写明的，标 **推导** 的是按它的规则补出来的。
- 对应代码：令牌在 `src/styles/tokens.css`，组件在 `src/components/`，页面在 `src/features/`。
- 当前状态：八个页面可用（今天、本周、任务、副业、收支、概览、回顾、例行），浅色主题；在线版多了登录页、同步图标和访问令牌弹窗；界面有中文和英文两种语言。
- 最近更新：2026-09-30
- 官网（`site/`）是另一套视觉，规格见 [前端设计：官网](前端设计-官网.md)。

## 页面结构

| 页面 | 结构 | 来源 |
| --- | --- | --- |
| 今天 | 三列：今天的计划（卡片 + 快速添加 + 做完的收成短行）/ 时间线 / 例行、收支、投入；桌面上三列各自滚动 | 推导（看板三列用在日计划上） |
| 本周 | 左三列宽度放七个按天分组（过去的日子收成一行，有没做完的才展开），右一列放「之前没做完」和「还没安排」卡片 | 推导 |
| 任务 | 看板 / 列表；想法、待办、进行中三列展开，已完成、已搁置收成短行 | 提炼 |
| 副业 | 按阶段排看板：构思、搭建中、运营中展开，暂停、已结束收成短行；点卡片右侧出详情 | 提炼 |
| 收支 | 分组列表：待到账一组固定在最上面，其余按月，三个月前的默认收起；组标题右侧写收入、支出、净收入 | 推导 |
| 概览 | 主图卡四个页签（净收入 / 投入时间 / 时薪 / 完成任务），下面副业、钱、时间三列，右侧本期结束短行和动态 | 推导 |
| 回顾 | 小结一段话 + 完成的 / 时间 / 钱三列 + 三段复盘笔记；右侧往期 | 推导 |
| 例行 | 每天、每周、每月三列，停用的收成短行 | 提炼 |

### 卡片三层（提炼：三层）

| 卡片 | 第一层（12px 辅助字） | 第二层（13px） | 第三层 |
| --- | --- | --- | --- |
| 任务 | 开始时间、编号、已投入 / 预估、副业方块；悬停出现计时和更多 | 状态图形（点一下完成）+ 两行内标题 | 优先级、延期、截止、子任务进度 |
| 副业 | 本月净收入、投入小时、时薪、12 周净收入小柱图 | 副业方块 + 名称 | 月目标进度、下个里程碑、待办数 |
| 例行 | 连续几期、完成率、时长、副业方块 | 勾选 + 名称 | 打卡格子（按天 12 周 × 7 天，按周 16 格，按月 12 格） |

### 时间线

| 项目 | 值 |
| --- | --- |
| 刻度 | 每小时 56px，整点实线、半点虚线；左侧 44px 放时刻 |
| 吸附 | 拖动和键盘调整都按 15 分钟一格；最短 15 分钟 |
| 块 | 白底 1px 边框，左侧 3px 副业色条；低于 38px 只显示一行（标题 + 开始时间），否则两行；重叠的块并排；已完成的块浅灰底 |
| 现在 | 1px `--risk` 红线 + 6px 圆点；过去和未来的时段一样是白底，只靠这条线区分 |
| 操作 | 鼠标拖块改时间、拖下边改时长；从计划列表或建议拖进来直接排上；点空白处弹出没排时间的任务；选中块按上下键挪 15 分钟、按住 Shift 调时长；手指在时间线上只用来滚动 |

### 容量

每天的已排时长 = 当天任务的预估 + 每天 / 工作日例行的时长（每周、每月的例行只在做了的那天算）。容量条灰色是已排、深色是已完成，超出的部分用 `--progress` 黄接在后面，旁边写「超出 25m」，不只靠颜色。

### 颜色的用法

- 紫色实心勾只表示「做完了」：完成的任务、达成的里程碑、打过卡的格子。
- 黄色只表示「进行中 / 在路上」：进行中的任务、计时中、待到账、延期。
- 红色只用于逾期、紧急优先级、现在线。
- 副业颜色只出现在 16px 以内的小方块和时间块左侧的色条上。
- 图表一律中性深灰，对比期是浅灰虚线；负数用更浅的灰画在基线下面。

| 窗口栏 AI 动态 | 同步图标左边，24px 见方灰色图标按钮（`Sparkles`），悬停浅灰底，提示「AI 动态」；有等待采纳的提议时右上角数字角标：14px 高、最小 14px 宽的圆角块，`--text-primary` 底、窗口底色字、10px 等宽数字，超过 9 写「9+」 |
| AI 动态抽屉 | 右侧抽屉 460px；「待采纳 / 全部」分段；改动包卡片（令牌名 · 时间 · 状态，概括一行，理由一行次要文字，可展开明细）；待采纳给「采纳」「不要」，已生效给「撤销」；加载三条灰块、失败给「重试」、空时一句话；细节见 [AI 改动记录](模块设计/AI改动记录.md#界面) |

## 多语言

| 位置 | 做法 |
| --- | --- |
| 头像菜单 | 「键盘快捷键」下面一项「语言」，展开是单选的「中文 / English」，语言名不跟着界面语言变 |
| 文字长度 | 英文普遍比中文长：标签列按最宽的标签自适应（不写死几个字宽），窄列里的文字不换行、放不下就截断；图表纵轴按最长的刻度文字留宽 |
| 英文写法 | 句首大写其余小写；按钮动词开头；叫法统一见 [多语言](模块设计/多语言.md) 的「英文统一叫法」 |
| 数字 | 金额、日期都走统一的格式化函数，不在页面里拼货币符号或「万」 |

## 状态画法

| 情况 | 画法 |
| --- | --- |
| 加载 | 页面脚本就绪前先画同样的骨架（窗口栏、侧栏、两条栏、灰块） |
| 空 | 一枚细线图标 + 一句话 + 至多一个动作（如「清除筛选」） |
| 错误 | 页面出错给「重试」；表单就地红字；本地保存失败弹出带「重试」的提示，说明修改仍然有效 |
| 长文本 | 卡片标题两行截断，列表单行截断，悬停显示全文 |
| 焦点 | 所有可操作元素都有 2px 中性灰描边 |

## 动效

悬停变色 120ms，弹层 150ms 淡入 + 轻微缩放；系统开启「减少动态效果」时全部关闭。

## 响应式

| 宽度 | 变化 |
| --- | --- |
| ≥ 1280 | 今天三列各自滚动；本周左三右一；概览、回顾右侧一列 |
| 1024–1279 | 今天变两列（计划 / 时间线），例行、收支、投入移到下方 |
| < 1024 | 侧栏收进抽屉；右下角出现快速记录圆钮 |
| < 768 | 单列；时间线限高 560px 自己滚动；看板横向滑动并按列吸附 |

任务行、收支行本身是尺寸容器，按自己的宽度决定显示哪些列，放进 460px 的详情侧栏时标题不会被挤没。

## 落地方式

- 令牌：`src/styles/tokens.css`（`:root` 变量 + Tailwind `@theme` 字号、圆角、阴影），`src/app/globals.css` 把变量映射成工具类。
- 组件：`src/components/ui` 是按令牌改过尺寸的 shadcn 组件；`src/components/base` 是状态图形、标签、涨跌、看板列等小部件。
- 页面：`src/features/shell` 是外框，其余每个目录一个页面；`common` 是共用部件，`forms` 是表单。
- 模块文档：[工程与目录](模块设计/工程与目录.md)、[版本切换](模块设计/版本切换.md)、[同步](模块设计/同步.md)、[登录与令牌](模块设计/登录与令牌.md)、[多语言](模块设计/多语言.md)、[AI 改动记录](模块设计/AI改动记录.md)。
- 界面文字：全部在 `src/i18n/messages/<语言>/` 的词条里，页面里不写死文字。
