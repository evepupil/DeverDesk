# 多语言

- 模块定位：界面文字、日期、时长、金额按用户选的语言显示；快速添加同时认中文和英文写法。
- 对应代码：`src/i18n/`（`locales.ts` 语言列表、`runtime.ts` 当前语言和货币、`react.ts` 组件里取词条、`messages/` 各语言词条）、`src/features/shell/locale-boundary.tsx`（切换时重画工作台、同步页面语言标记和标题）、`src/domain/calendar.ts` 与 `src/domain/format.ts`（按当前语言出日期和数字）、`src/data/catalog.ts`（状态、分类等叫法取自词条）
- 所属里程碑：[M3 多语言地基](../roadmap.md#m3)
- 界面规格：[前端设计](../前端设计.md)
- 当前状态：进行中
- 最近更新：2026-09-30

## 职责与边界

负责：记住用户选的语言（没选过按浏览器语言猜）；给组件和计算函数提供当前语言的词条；按语言格式化日期、时长、金额；切换语言后整页换成新语言。
不负责：用户自己写的内容（任务标题、备注、副业名）不翻译；服务器接口返回的错误原文不直接给人看，由浏览器按状态码换成当前语言的话。

## 结构与数据流

```
第一次打开：本机存过语言？ ─是→ 用它
                          └否→ 浏览器语言以 zh 开头用中文，其余用英文
                                   │
                    runtime：当前语言 + 当前货币（来自个人设置）
                    ├─ 组件：useT() 取词条对象，比如 t.tasks.empty
                    ├─ 计算函数：getT() 取词条，日期、时长、提醒文字按当前语言拼
                    └─ 状态叫法：catalog 里的 label 是取词条的读取器，用法不变
切换语言 → 存进本机 → 通知订阅者 → 工作台按「语言 + 货币」换一个 key 整个重画
```

词条按命名空间分文件：`messages/zh-CN/<空间>.ts` 和 `messages/en/<空间>.ts` 一一对应。中文词条是基准，英文词条的类型从中文推出来，少一条、多一条、参数对不上都会类型检查报错。带数字的词条写成函数，比如 `(n: number) => \`${n} 条改动\``，英文在函数里处理单复数。

| 命名空间 | 放什么 | 对应代码 |
| --- | --- | --- |
| `words` | 各处通用的词：保存、取消、删除、重试…… | 全局 |
| `calendar`、`format` | 星期、月日、相对日期、多久以前；时长全写、百分点 | `src/domain/calendar.ts`、`format.ts` |
| `catalog` | 任务状态、优先级、副业阶段、例行频率、收款渠道、收支分类、到账状态 | `src/data/catalog.ts` |
| `nav` | 页面名、常用视图名 | `src/features/shell/nav.ts` |
| `quickAdd` | 快速添加识别出的标记怎么显示 | `src/domain/quick-add.ts` |
| 各页面同名空间 | `shell`、`common`、`forms`、`today`、`week`、`tasks`、`projects`、`ledger`、`insights`、`review`、`routines`、`auth`、`sync`、`edition`、`app`、`components` | `src/features/<同名目录>/`、`src/app/`、`src/components/` |

## 关键决策

| 决策 | 理由 |
| --- | --- |
| 自己写一层很薄的词条机制，不引入第三方多语言库 | 页面是纯静态导出、全在浏览器渲染，不需要按语言分路由；词条直接是 TypeScript 对象，取词条有自动补全，漏翻由类型检查拦下 |
| 词条是对象属性（`t.tasks.empty`），不用字符串键 | 写错名字编译就报错；带参数的词条直接是函数，参数类型也受检查 |
| 格式化函数和状态叫法保留原来的用法，内部按当前语言出文字 | 金额格式化有 50 多处调用、状态叫法遍布各页，改成传语言参数要动几十个文件；保留用法后，各页只需把写死的文字换成词条 |
| 切换语言或货币时整个工作台换 key 重画 | 计算函数不是订阅式的，重画一次最简单可靠；换语言很少发生，重画时关掉打开的弹层也合理 |
| 货币放在个人设置里（跟着数据同步），默认人民币；和语言无关 | 金额是记账用的币种，换界面语言不该让数字换币种 |
| 没选过语言时，中文浏览器用中文，其余一律英文 | 非中文用户看英文更容易上手 |
| 快速添加不管界面是什么语言，中英文写法都认 | 用户可能中英混着打 |
| 服务器错误按状态码在浏览器里换成当前语言 | 服务器接口的错误原文给程序看，界面上显示的话由浏览器决定 |
| 静态导出的页面按中文预渲染，挂载后切到实际语言 | 构建时不知道用户语言；工作台内容本来就在浏览器里渲染，看不到闪烁 |

## 当前实现

- 进行中：核心机制、日期与数字格式化、状态叫法、导航、快速添加英文写法、语言切换菜单由主会话完成；各页面文字按目录分路抽取。

## 验证方式

- `pnpm typecheck`：英文词条和中文词条逐条对齐。
- `pnpm test`：日期、时长、金额在两种语言下的输出；快速添加的英文写法；源码扫描测试确认词条文件以外没有写死的中文（注释、测试、样例数据除外）。
- `pnpm build:local && pnpm probe`：切到英文后逐页检查。
