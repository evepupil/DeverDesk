# 登录与令牌

- 模块定位：在线版的门。打开时先确认登录，没登录显示口令登录页；登录后可以在头像菜单里管理个人令牌（给以后的 AI 助手用）和退出登录。本地版没有这一层。
- 对应代码：`src/features/auth/`（`auth-gate.tsx` 登录门、`login-screen.tsx` 登录页、`tokens-dialog.tsx` 令牌弹窗）、`src/features/shell/workbench-shell.tsx`（头像菜单的「访问令牌」「退出登录」）、`src/app/(workbench)/layout.tsx`（工作台外面套登录门）；服务器端见 [云端接口](云端接口.md)
- 所属里程碑：[M2 在线版后端](../roadmap.md#m2)
- 界面规格：[前端设计 · 在线版的差异](../前端设计.md#在线版的差异)
- 当前状态：已完成
- 最近更新：2026-09-30

## 职责与边界

负责：判断能不能进工作台；口令登录的输入、提交和各种失败提示；登录后开始同步；登录过期时回到登录页；令牌的列出、新建（只显示一次）、撤销；退出登录。
不负责：口令校验、Cookie 签发、令牌存储（都在服务器端）；同步本身（见 [同步](同步.md)）。

## 结构与数据流

```
打开页面 → 登录门：加载骨架 → 查登录状态
             ├─ 已登录 ──────────→ 开始同步 → 工作台
             ├─ 没登录 ──────────→ 登录页 ─ 口令对了 ─→ 开始同步 → 工作台
             ├─ 断网 ────────────→ 用本机缓存进工作台（联网后自动同步）
             └─ 服务器出错 ──────→ 「连不上服务器」+ 重试
工作台里同步时被告知登录过期 → 回到登录页
```

## 关键决策

| 决策 | 理由 |
| --- | --- |
| 登录门包在工作台最外层，本地版直接放行 | 在线版的每个页面都受保护；本地版不受影响 |
| 断网时直接进工作台 | 离线也要能用，数据来自本机缓存 |
| 部署在 Cloudflare Access 后面时直接进工作台；只用 Access、没设口令时登录页不显示口令框 | Access 已经登录过，服务器直接认；没有口令可输 |
| 令牌只在新建后显示一次，关掉弹窗就再也看不到 | 服务器只存摘要，拿不回明文 |
| 用个人令牌登录的程序不能管理令牌 | 防止令牌泄露后被用来再发新令牌 |
| 退出前有未上传的改动要确认 | 退出会清掉本机数据，没传上去的改动会丢 |
| 断网时不让退出，提示联网后再退 | 登录凭证是脚本碰不到的 Cookie，只有服务器能清；断网时清掉本机数据也没用，联网后会自动登录回来 |

## 当前实现

- 登录页提示：没填口令「请输入访问口令」；口令不对「口令不对」；尝试太多写明几分钟后再试；断网和服务器出错各有一句。提交中按钮变「登录中…」并禁用，防止重复提交。
- 令牌弹窗每次打开重新读取列表；关闭时清掉刚新建的令牌和输入内容。
- 退出登录：调用退出接口（断网就提示联网后再退，到此为止）→ 停止同步 → 清掉本机缓存和队列 → 整页刷新回到登录页。

## 验证方式

- `pnpm build && pnpm e2e`：没登录显示登录页、口令不对就地提示、口令对了进工作台；用令牌调用建任务接口成功；退出后回到登录页且本机缓存已清。

## 待扩展项

- 多语言（M3）：登录页和令牌弹窗的文字进词条。
