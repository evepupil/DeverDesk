# 登录与令牌

- 模块定位：在线版的门。打开时先确认登录，没登录显示口令登录页；登录后可以在头像菜单的「连接 AI」里管理访问令牌（给 AI 助手连 MCP 用）和退出登录。本地版没有这一层。
- 对应代码：`src/features/auth/`（`auth-gate.tsx` 登录门、`login-screen.tsx` 登录页、`tokens-dialog.tsx` 连接 AI 弹窗、`connect-snippets.ts` 各客户端的连接配置）、`src/features/shell/workbench-shell.tsx`（头像菜单的「连接 AI」「退出登录」）、`src/app/(workbench)/layout.tsx`（工作台外面套登录门）；服务器端见 [云端接口](云端接口.md)、[MCP 服务](MCP服务.md)
- 所属里程碑：[M2 在线版后端](../roadmap.md#m2)；连接 AI 弹窗、令牌权限、时区自动补齐属于 [M4](../roadmap.md#m4)
- 界面规格：[前端设计 · 在线版的差异](../前端设计.md#在线版的差异)
- 当前状态：M2 部分已完成；M4 部分进行中
- 最近更新：2026-10-01

## 职责与边界

负责：判断能不能进工作台；口令登录的输入、提交和各种失败提示；登录后开始同步；登录过期时回到登录页；令牌的列出、新建（带权限，只显示一次）、改权限、撤销；新建后给出各个 AI 客户端的连接配置；登录后发现作息设置没有时区时自动补上浏览器的时区；退出登录。
不负责：口令校验、Cookie 签发、令牌存储（都在服务器端）；同步本身（见 [同步](同步.md)）。

## 连接 AI 弹窗（M4）

原「访问令牌」弹窗改名「连接 AI」，宽 560px（要放得下配置代码）：

| 区块 | 做法 |
| --- | --- |
| 已连接列表 | 每行：名称；下面一行「几月几日创建 · 几月几日用过 / 没用过」；右侧权限下拉（只看 / 只能提议 / 直接改，改了立即保存，失败回到原值并提示）和「撤销」（二次确认，沿用原做法） |
| 新建 | 名称输入框（例如「Claude Code」，1–40 字）+ 权限三选一（分段选择，默认「只能提议」，下面一行小字说明选中的那档：只看「只能查看数据」、只能提议「改动要你在 AI 动态里采纳」、直接改「改动立即生效，可以撤销」）+「新建」 |
| 新建之后 | 只显示一次的令牌（只读框 + 复制，沿用原做法）；下面按客户端分段：Claude Code / Codex / Cursor / VS Code / 其他，每段一个等宽字体的代码块和「复制」，内容用本站地址 `<当前域名>/mcp` 和刚建的令牌填好 |
| 提示 | 只在当前是 Access 登录时多一句：「部署在 Cloudflare Access 后面时，需要给 /mcp 加一条绕过规则」 |

各客户端配置（内容固定在 `connect-snippets.ts`，地址和令牌填进去）：

- Claude Code：`claude mcp add --transport http deverdesk <地址> --header "Authorization: Bearer <令牌>"`
- Codex：`~/.codex/config.toml` 里 `[mcp_servers.deverdesk]`、`url = "<地址>"`、`http_headers = { "Authorization" = "Bearer <令牌>" }`
- Cursor：`~/.cursor/mcp.json`：`{"mcpServers":{"deverdesk":{"url":"<地址>","headers":{"Authorization":"Bearer <令牌>"}}}}`
- VS Code：`.vscode/mcp.json`：`{"servers":{"deverdesk":{"type":"http","url":"<地址>","headers":{"Authorization":"Bearer <令牌>"}}}}`
- 其他：地址一行、请求头一行

## 时区自动补齐（M4）

登录门在进入工作台、本机数据就绪后检查作息设置：没有 `timeZone` 时写入浏览器的时区（`Intl.DateTimeFormat().resolvedOptions().timeZone`），走普通的改作息设置流程，会同步到服务器。已有时区不覆盖（换了地方要用户自己在作息设置里改）。作息设置弹窗里加「时区」下拉：常用时区列表 + 当前值 + 浏览器时区，显示为「Asia/Shanghai（UTC+08:00）」。

## 结构与数据流

```
打开页面 → 登录门：加载骨架 → 查登录状态
             ├─ 已登录 ──────────→ 开始同步 → 工作台
             ├─ 没登录 ──────────→ 登录页 ─ 口令对了 ─→ 开始同步 → 工作台
             ├─ 断网 ────────────→ 用本机缓存进工作台（联网后自动同步）
             └─ 服务器出错 ──────→ 「连不上服务器」+ 重试
工作台里同步时被告知登录过期 → 回到登录页
```

## 关键决策

| 决策 | 理由 |
| --- | --- |
| 登录门包在工作台最外层，本地版直接放行 | 在线版的每个页面都受保护；本地版不受影响 |
| 断网时直接进工作台 | 离线也要能用，数据来自本机缓存 |
| 部署在 Cloudflare Access 后面时直接进工作台；只用 Access、没设口令时登录页不显示口令框 | Access 已经登录过，服务器直接认；没有口令可输 |
| 令牌只在新建后显示一次，关掉弹窗就再也看不到 | 服务器只存摘要，拿不回明文 |
| 用个人令牌登录的程序不能管理令牌 | 防止令牌泄露后被用来再发新令牌 |
| 新建令牌默认「只能提议」 | 先让 AI 的改动都经过用户一次，放心了再在列表里改成「直接改」 |
| 连接配置把令牌直接写进代码块 | 用户复制一次就能用；令牌只显示这一次，关掉弹窗后配置也不再显示 |
| 时区只在没有时补，不随浏览器变 | 几台设备在不同时区时不会来回改；在线版服务器只认作息设置里这一个时区 |
| 退出前有未上传的改动要确认 | 退出会清掉本机数据，没传上去的改动会丢 |
| 断网时不让退出，提示联网后再退 | 登录凭证是脚本碰不到的 Cookie，只有服务器能清；断网时清掉本机数据也没用，联网后会自动登录回来 |

## 当前实现

- 登录页提示：没填口令「请输入访问口令」；口令不对「口令不对」；尝试太多写明几分钟后再试；断网和服务器出错各有一句。提交中按钮变「登录中…」并禁用，防止重复提交。
- 令牌弹窗每次打开重新读取列表；关闭时清掉刚新建的令牌和输入内容。
- 退出登录：调用退出接口（断网就提示联网后再退，到此为止）→ 停止同步 → 清掉本机缓存和队列 → 整页刷新回到登录页。

## 验证方式

- `pnpm build && pnpm e2e`：没登录显示登录页、口令不对就地提示、口令对了进工作台；用令牌调用建任务接口成功；退出后回到登录页且本机缓存已清。
