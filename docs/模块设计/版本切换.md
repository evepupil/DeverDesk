# 版本切换

- 模块定位：同一套代码打包成本地版或在线版，以及本地版独有的说明弹框、GitHub 图标、访问统计和演示站部署。
- 对应代码：`src/lib/edition.ts`、`src/features/edition/`、`scripts/build.mjs`、`deploy/demo/wrangler.jsonc`；接入点在 `src/features/shell/workbench-shell.tsx`、`workbench-sidebar.tsx`、`src/app/layout.tsx`
- 所属里程碑：[M1 本地版 / 在线版切换](../roadmap.md#m1)
- 当前状态：已完成
- 最近更新：2026-09-30

## 职责与边界

负责：打包时决定版本；本地版的界面差异；把本地版部署成演示站。
不负责：数据存在哪（见 [存储层](存储层.md)）；在线版的登录和同步（M2）。

## 结构与数据流

```
打包：node scripts/build.mjs --edition local|cloud（默认 cloud）
        │ 设置环境变量 NEXT_PUBLIC_DEVERDESK_EDITION，打包时写进页面代码
        ▼
src/lib/edition.ts  →  IS_LOCAL_EDITION 等常量
        │
        ├─ 本地版：窗口栏右上角 GitHub 图标；第一次打开弹说明；品牌菜单「关于本地版」；配了令牌就加访问统计
        └─ 在线版：以上都不出现
```

| 环境变量 | 作用 | 默认 |
| --- | --- | --- |
| `NEXT_PUBLIC_DEVERDESK_EDITION` | `local` 是本地版，其余是在线版 | 在线版 |
| `NEXT_PUBLIC_DEVERDESK_REPO_URL` | GitHub 图标和「部署在线版」指向的仓库，fork 后可换成自己的 | `https://github.com/evepupil/DeverDesk` |
| `NEXT_PUBLIC_DEVERDESK_ANALYTICS_TOKEN` | Cloudflare 网页统计令牌，只在本地版生效；演示站的令牌写在仓库根目录不提交的 `.env.production.local` 里，`next build` 自动读取 | 空（不统计） |

## 关键决策

| 决策 | 理由 |
| --- | --- |
| 打包时切换，不在运行时切换 | 本地版演示站是纯静态文件，不需要也不应该带在线版的登录流程 |
| 默认在线版 | 在线版是主要形态；演示站打包时显式指定本地版 |
| 说明弹框只自动弹一次，之后从品牌菜单打开 | 讲清「数据只在这个浏览器」这个风险一次就够，不反复打扰 |
| 说明里提示「导出备份 → 部署在线版 → 导入」 | 已有备份导出 / 导入，就是从本地版搬到在线版的通道 |
| 演示站用只有静态资源的 Worker 部署 | 本地版服务端不存任何东西；和在线版一样放在 Workers 上，部署方式统一 |
| 演示站放在 app 子域名 | 主域名留给官网（介绍产品的落地页），演示站是「打开就能用」的应用本身 |
| 访问统计只在本地版、并且配了令牌时加载 | 演示站用来看获客效果；在线版是用户自己的部署，不统计 |
| GitHub 图标和「部署在线版」只写 noopener，不加 noreferrer | 两个都指向自家仓库；留下来源，GitHub 仓库的流量页才数得到演示站带去多少人 |

## 当前实现

- 说明弹框：标题「你在用本地版」，两段说明，按钮「部署在线版」和「知道了」；「部署在线版」按界面语言打开英文 README（仓库首页）或中文 README 里讲部署的那一节；看过的记号存在浏览器 `deverdesk:local-notice-seen`，存不上时当作看过。
- GitHub 图标：和窗口栏其他图标按钮同尺寸，新窗口打开仓库。
- 访问统计：`src/features/edition/analytics.tsx` 在页面可交互后加载 Cloudflare 网页统计脚本，页面切换也会记（统计脚本自己监听地址变化）。演示站和官网共用 Cloudflare 后台 Web Analytics 里 deverdesk.com 这一个站点（手动加脚本的模式），看数据时按主机名选 app.deverdesk.com；来源里的 deverdesk.com 就是从官网点「在线试用」过来的人。
- 演示站：`pnpm deploy:demo` 打包本地版并部署到名为 `deverdesk-demo` 的 Worker，绑定自定义域名 app.deverdesk.com（域名需要已经在同一个 Cloudflare 账号里；首次部署时 Cloudflare 自动建好 DNS 记录和证书）。已上线：https://app.deverdesk.com 。主域名 deverdesk.com 和 www 留给官网（落地页），不归演示站。部署前确认根目录 `.env.production.local` 里有统计令牌，没有就不统计。
- 在线版的产物里仍带着本地版组件的代码，但不会渲染；体积很小，暂不处理。

## 验证方式

```bash
pnpm build:local && pnpm probe     # 含「第一次打开弹说明」「关掉后刷新不再弹」「GitHub 图标指向仓库」；核对时统计脚本被拦下，不往后台报数
pnpm build                         # 在线版能正常打包；页面上不出现说明弹框和 GitHub 图标
pnpm exec wrangler deploy -c deploy/demo/wrangler.jsonc --dry-run   # 检查演示站配置
```
