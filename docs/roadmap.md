# 路线图

目标：做一个开源的、独立开发者自己用的一人公司控制台。本地版打开就能用（数据留在浏览器），在线版部署到用户自己的 Cloudflare，多设备同步；两个版本同一套代码。

| 里程碑 | 目标 | 状态 | 依赖 | 模块文档 | 退出标准 |
| --- | --- | --- | --- | --- | --- |
| <a id="m0"></a>M0 独立仓库 | 只含工作台的公开仓库，AGPL 许可证 | 已完成 | — | [工程与目录](模块设计/工程与目录.md) | 类型检查、代码检查、构建通过；20 项交互检查通过；推到 GitHub |
| <a id="m1"></a>M1 本地版 / 在线版切换 | 数据读写抽成可替换的存储层；打包时切换版本（默认在线）；本地版弹框说明、GitHub 图标、访问统计 | 已完成 | M0 | [存储层](模块设计/存储层.md)、[版本切换](模块设计/版本切换.md) | 本地版构建能直接部署成演示站；存储层换实现时页面不用改 |
| <a id="m2"></a>M2 在线版后端 | Cloudflare Worker + D1；口令登录（可选 Cloudflare Access）；按条同步、离线可用；一键部署按钮；接口给 MCP 留好位置 | 已完成 | M1 | [云端接口](模块设计/云端接口.md)、[同步](模块设计/同步.md)、[登录与令牌](模块设计/登录与令牌.md) | 本机模拟环境里两台「设备」改同一份数据能正确合并；一键部署配置齐全 |
| <a id="m3"></a>M3 多语言地基 | 界面文字抽成词条；语言设置；日期、货币按语言格式化；快速添加支持英文写法 | 已完成 | M1 | [多语言](模块设计/多语言.md) | 页面里不再有写死的中文；切换语言后各页正常 |
| <a id="m4"></a>M4 自动记账与 MCP | 收支来源自动同步；让 AI 助手读写数据 | 未开始（暂缓） | M2 | — | — |
| <a id="m5"></a>M5 官网 | 首页、更新日志、博客，中英文两套；体现全部开源；「在线试用」跳到演示站 | 已完成 | M3 | [官网](模块设计/官网.md) | 四类页面中英文全部导出；单测、类型检查、代码检查、打包通过；交互核对全过；手机与桌面不横向溢出；部署到 deverdesk.com |
