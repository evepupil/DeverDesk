# 前端设计：官网

- 一句话方向：照 Aceternity「Simplistic SaaS Template」复刻——白底、深灰大标题、蓝色渐变主按钮、首屏右上一条斜向蓝色光带、浏览器框里放产品真截图、圆角白卡配一圈极细描边和很浅的阴影、页脚底部一行超大描边品牌字。
- 参考来源：

  | 站点 | 借鉴了什么 |
  | --- | --- |
  | Aceternity Simplistic SaaS Template（simplistic-saas-template.vercel.app） | 全站骨架和视觉：顶栏滚动行为、首屏排版和光带、功能 Bento 的排法、评价墙的点状底纹和飘着的卡片、多端展示的三个设备和虚线连线、分组折叠的常见问题、左字右拼贴的收尾区、页脚四列 + 超大描边字；字号、颜色、圆角、阴影都按它实测的数值 |
  | Aceternity Timeline 组件 | 更新日志：左侧大号版本号吸顶，中间竖线随滚动点亮 |
  | Aceternity Blog With Search / Blog Content With TOC / Simple Blog With Grid（付费区块，照公开预览复刻） | 博客列表的置顶大卡、搜索框加一行一篇；文章页的左侧目录、封面大图和正文排版；列表页头的浅方格底纹 |
  | Twenty | 顶栏里「GitHub 图标 + 星数」的按钮 |
  | Linear 更新日志 | 每条更新「日期、标题、配图、正文」的排法 |

- 对应代码：`site/`（独立的 Next.js 项目）。令牌在 `site/src/app/globals.css`，共享组件在 `site/src/components/site/`，Aceternity 组件在 `site/src/components/aceternity/`，各页区块在 `site/src/sections/`。
- 当前状态：首页、更新日志、博客列表、博客文章四类页面中英文两套已完成，只有浅色。
- 最近更新：2026-09-30

产品本身（工作台）的界面规格见 [前端设计](前端设计.md)，两边是两套独立的视觉：工作台是安静的小字号工具，官网是营销页。

## 设计令牌

### 颜色

| 令牌（Tailwind 类名） | 值 | 用途 |
| --- | --- | --- |
| `brand-primary` | `#1E90FF` | 主按钮渐变下沿、光带最深那条、时间线光束、选中描边。白底上对比度只有 3.2:1，不做文字 |
| `brand-secondary` | `#5CB3FF` | 主按钮渐变上沿、光带第二条 |
| `brand-deep` | `#0A6FD6` | 白底上的蓝色文字和文字链接（4.9:1） |
| `brand-soft` | `#EAF4FF` | 蓝色浅底：「新增」标签、置顶徽标、图标圆底 |
| 光带四色 | `#1E90FF` `#5CB3FF` `#9CCFFF` `#D6EBFF` | 首屏、更新日志页头、文章收尾卡的四道斜条（只在 SVG 里用） |
| `dd-progress` / `dd-warn` | `#E5A50A` / `#8A6100` | 插画里的「进行中、待到账」；黄色做文字时用加深的 `dd-warn`（5.5:1） |
| `dd-done` | `#6E56CF` | 插画里的「已完成」 |
| `dd-risk` | `#E5484D` | 插画里的「逾期、现在线」，不做正文 |
| `dd-good` | `#17774A` | 「已到账」「修复」标签的文字（5.6:1） |
| `label-*` 十色 | 同产品 | 插画里副业的小方块和时间块色条 |

中性色用 Tailwind 自带的 `neutral` 色阶：大标题 `neutral-700`（#404040，10.4:1），卡片标题 `neutral-900`，正文 `neutral-600`（#525252，7.8:1），辅助小字最浅到 `neutral-500`（#737373，4.7:1）；`neutral-400` 及更浅只做图标和装饰。线条 `neutral-200`，浅底 `neutral-50`。

### 字

- 字族：`"Inter Variable"`（拉丁字母和数字，随站点打包，不走字体网站）+ 系统中文黑体（PingFang SC、Hiragino Sans GB、Microsoft YaHei、Noto Sans SC）；等宽用系统等宽字体。
- 字号阶梯：

  | 用途 | 手机 → 桌面 | 字重 |
  | --- | --- | --- |
  | 首屏大标题 | 36 → 72px，行高 1.12 → 1.04，字距 -0.025em | 500 |
  | 区块标题 | 24 → 36 → 48px，字距 -0.025em | 400 |
  | 收尾区大标题 | 30 → 36 → 48px | 700 |
  | 首屏副标题 | 16 → 20px | 400 |
  | 区块副标题 | 14 → 16 → 18px | 400 |
  | 正文 | 16px / 24px | 400 |
  | 卡片标题 / 卡片正文 | 14px | 600 / 400 |
  | 辅助小字 | 12px | 400 |

- 标题一律「只在标点和空格处换行」（`break-keep`）加「行长平衡」（`text-balance`）：中文标题不会把一个词拆到两行，英文标题不会只剩一个词在最后一行。

### 间距、圆角、阴影

- 容器：最宽 1280px，左右 16px（手机）/ 32px（平板起），桌面内容区 1216px。区块上下留白 40 → 80 → 128px。间距按 Tailwind 的 4px 阶梯。
- 圆角：按钮 8px、浏览器框 14px、卡片 18px、悬浮顶栏 24px（和模板实测一致）。
- 阴影：Bento 卡片 `shadow-sm` + 1px 黑色 10% 描边；轻卡 `shadow-sm` + 5% 描边；浮起的卡 `shadow-lg` + 5% 描边；悬浮顶栏 `0 1px 3px rgba(0,0,0,.1), 0 1px 2px -1px rgba(0,0,0,.1)` + 80% 白底 + 背景模糊。
- 主按钮：蓝色上浅下深的渐变、白字带 1px 文字阴影、内高光；次按钮：白底 + 1px `neutral-200` 描边。高度 36px（顶栏）/ 48px（页面）。

## 明暗主题

只有浅色。产品本身只有浅色，截图放在暗底上反差太大；模板的暗色切换按钮也没有做。

## 布局与响应式

| 宽度 | 变化 |
| --- | --- |
| ≥ 1024 | 顶栏横排四个链接 + 语言切换 + GitHub 按钮 + 「在线试用」 |
| < 1024 | 顶栏收成 GitHub 按钮 + 菜单按钮，菜单从顶栏下方展开 |
| ≥ 768 | Bento 三列（左右通高、中间两张半高）；产品导览文字 4/12、截图 8/12；两种用法显示三点连线 |
| < 768 | 所有多列改单列；场景墙改成标题 + 3 张卡的纵向排列；两种用法不显示连线 |

验收看手机 390 和桌面 1440 两档，所有页面在两档下都不横向溢出（核对脚本实测）。

| 主按钮 | 蓝色渐变 | 外发光加深 | 缩到 98% | 半透明、不可点 | 静态站没有提交动作，不出现 | 同左 |

## 空态、加载、错误

- 空：博客搜索没有结果时，一枚搜索图标 + 一句「没有找到和「关键词」有关的文章。」+「清除搜索」按钮。
- 加载：截图和封面加载中是 `neutral-50` / `neutral-100` 底，宽高写在图片上，页面不跳动。
- 拿不到数据：GitHub 星数拿不到时不显示数字（顶栏只写「Star」），最近提交用打包时的快照；星数少于 100 时也不显示数字。
- 错误：不存在的地址显示中英双语 404 页，给两个语言的首页入口。

## 动效

- 只动位移和透明度；缓动 `cubic-bezier(0.22, 1, 0.36, 1)`。
- 顶栏：往下滚超过 120px 藏起（300ms），往上滚变成悬浮圆角条。
- 产品导览切换截图淡入淡出 250ms；常见问题展开收起 250ms，加号转 45°；场景墙亮卡每 4 秒换一张（500ms）。
- 装饰循环：快速添加的打字、拖动卡上下浮动、红点呼吸、两种用法连线上的流动光段、更新日志竖线随滚动点亮。
- 内容永远不藏在动画后面：服务端渲染出来就是完整画面，动画在页面接管后才开始。
- 系统开了「减少动态效果」：所有循环停在最终画面，切换不做过渡。

## 无障碍底线

- 正文对比度 ≥ 4.5:1（最浅的文字色 `neutral-500` 为 4.7:1）；彩色只在图形里用，做文字时用加深版。
- 键盘可达：顶栏菜单按 Esc 关闭；产品导览页签支持 ← → Home End；常见问题每题是一个按钮，收起的答案读屏和 Tab 都跳过。
- 每页有「跳到正文」链接；新窗口打开的链接带读屏提示；装饰图和插画整块对读屏隐藏。

## 落地方式

- 令牌：`site/src/app/globals.css` 的 `@theme`（颜色、字族、圆角），Tailwind 4 自动生成对应的类名；阴影、按钮、卡片的完整类名串在 `site/src/lib/styles.ts`。
- 页面文字：`site/src/i18n/messages/zh.ts`、`en.ts`，组件里不写死文字。
- 实现它的模块文档：[官网](模块设计/官网.md)。
