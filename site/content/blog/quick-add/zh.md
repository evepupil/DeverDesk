想到一件要做的事时，先把它记下来，比立刻打开多个字段逐个填写轻松。DeverDesk 的快速添加允许你把标题和几个标记写在一行里；系统识别标记后，会把剩下的文字作为任务标题。

## 标记之间用空格隔开

基本写法是「标题 + 标记」。标题可以是普通文字；识别出来的时长、副业、日期和优先级会从标题中分开。中英文输入都能用，当前界面显示中文或英文，不影响解析。

时长可以写 `30m`、`1.5h`、`1h30m`、`2小时`、`45min` 或 `2hr`。支持小时和分钟的常见缩写，也支持小数小时；例如 `1.5h` 会换算成 90 分钟，`1h30m` 也是 90 分钟。

副业标记以 `#` 开头，例如 `#模板商城`、`#接口中转`、`#技术博客`、`#付费咨询` 或 `#公众号`。名称需要对应已有副业；系统会按名称匹配。日期可以写 `今天`、`明天`、`周五`、`下周二`、`10-3`、`10月3日`，也可以写 `today`、`tomorrow`、`fri`、`friday` 或 `next tue`。优先级用 `!`、`!!`、`!!!`：一个感叹号表示中，两个表示高，三个表示紧急。

## 看五个实际写法

| 输入 | 识别结果 |
| --- | --- |
| `写周报 30m #技术博客 明天 !!` | 标题「写周报」；30 分钟；副业「技术博客」；明天；高优先级 |
| `整理商品页 1.5h #模板商城 friday !!!` | 标题「整理商品页」；90 分钟；副业「模板商城」；最近的周五；紧急 |
| `检查接口 1h30m #接口中转 next tue !` | 标题「检查接口」；90 分钟；副业「接口中转」；下周二；中优先级 |
| `回咨询邮件 2小时 #付费咨询 10-3 !!` | 标题「回咨询邮件」；120 分钟；副业「付费咨询」；10 月 3 日；高优先级 |
| `起草通讯 45min #公众号 周五 !!!` | 标题「起草通讯」；45 分钟；副业「公众号」；最近的周五；紧急 |

每一行里的标记可以换顺序；它们之间用空格分隔，识别后任务标题只保留其他文字。比如副业名没有匹配到已有项目时，`#` 后的文字不会凭空创建项目，会作为普通标题内容保留。

## 在手机和键盘上快速开始

手机界面右下角有快速记录按钮，适合把临时想到的任务先放进列表。坐在电脑前时，可以用 `Ctrl` / `⌘` + `K` 打开命令面板搜索工作台内容，再继续整理任务。快速添加负责把一行文字拆成任务信息，命令面板则负责搜索，两者配合能减少来回切换。

DeverDesk 有[任务、副业和概览等页面](/zh/blog/why-deverdesk/)；任务添加后，可以在任务页补充状态或在今天、本周安排时间。若想了解每个副业如何汇总投入与收支，可读[时薪计算方法](/zh/blog/hourly-rate/)。一行记录不会代替后续整理，但能帮你先抓住刚冒出来的想法。

## 中英文混着输入也可以

快速添加不跟着界面语言限制输入法。中文界面可以写 `tomorrow` 或 `45min`，英文界面也能用 `明天`、`下周二`。日期和优先级的识别标记会按当前语言显示名称，任务标题则保留你实际输入的文字。

如果整行都被当成标题，检查标记是否拼对、是否由空格隔开，以及副业名是否存在。可以先从最短的写法开始：标题加一个时长，确认后再添副业、日期和优先级。记录越及时，越容易把任务安排到真正可用的时间里。

## 把快速记录接到日常安排

例如，你想到要检查接口时，可以先写标题、时长、`#接口中转` 和一个日期，再继续处理手头的工作。打开任务页后，已经识别的副业和日期会留在对应字段里，标题也更容易一眼读懂。要是任务后来需要调整日期或优先级，可以在任务列表或今天、本周的安排里继续处理。

快速添加会识别一组明确的标记，不需要把句子写成完整指令。标题里可以有普通词语，只有符合时长、日期、优先级格式的词才会作为标记处理。副业标记还需要匹配现有副业，所以第一次使用时，可以先在副业页确认名称，再把名称接在 `#` 后面。英文界面也可以直接输入中文标记；中文界面同样可以输入英文的日期和时长。

手机上适合用右下角按钮先记下刚想到的事，之后再整理；电脑上可用快速添加记录，再用 `Ctrl` 或 `⌘` + `K` 搜索工作台。一个负责捕捉新任务，一个帮助找到已有内容。无论使用哪种入口，及时记下标题和大致时长，都能减少之后回想「那晚到底做了什么」的工作。
