在线版除了给你自己用，还是一个 [MCP](https://modelcontextprotocol.io) 服务。MCP 是让 AI 助手调用外部工具的统一协议：Claude Code、Codex、Cursor、VS Code 这类工具连上它，就能替你查今天的安排、记一笔收入、把任务排进空档。ChatGPT、Claude 的网页版和手机 App 走 OAuth，在网页上点一下「允许」就连上，不用复制令牌。

这个入口只有在线版有：本地版的数据只在浏览器里，没有可以连的服务。部署在线版的步骤见 [Cloudflare 部署指南](/zh/blog/deploy-to-cloudflare/)。

## 先想好让它做到哪一步

连接时要选一档权限：

- **只看**：只能读取你的数据。
- **只能提议**（默认）：它想改的内容先排队，等你在「AI 动态」里采纳才生效。
- **直接改**：改动立即生效，随时可以撤销。

刚开始建议用默认的「只能提议」，看几天它提的改动合不合你的习惯，再决定要不要放开到「直接改」。

## 用令牌连：Claude Code、Codex、Cursor、VS Code

打开头像菜单里的「连接 AI」，写上用途，选好权限，复制弹窗里对应客户端的配置。令牌只显示这一次，请当场保存。Claude Code 的写法是：

```bash
claude mcp add --transport http deverdesk https://你的域名/mcp \
  --header "Authorization: Bearer dd_你的令牌"
```

这几个工具也可以只填地址、不带令牌，连接时在浏览器里点允许。原来的令牌方式照常可用。

## 用 OAuth 连：ChatGPT、Claude 网页版和手机 App

1. 复制「连接 AI」弹窗最上面的连接器地址，形如 `https://你的域名/mcp`。
2. ChatGPT：在设置里打开开发者模式，新建一个连接器，填这个地址。Claude：打开 设置 → 连接器 → 添加自定义连接器。网页版加好的连接器，手机 App 里也能用。
3. 浏览器会打开 DeverDesk 的授权页。页面上写着是哪个应用要连、授权后会跳回哪个网站；你登录、选权限（默认「只能提议」），点「允许」。

授权之后，应用拿到的是一把一小时有效、能自己续期的钥匙，三十天不用就会失效。它会出现在「连接 AI」列表里，和手动建的令牌放在一起，可以改权限，也可以随时点「断开」，断开后它的下一次请求就会被拒绝。

如果你的在线版放在 Cloudflare Access 后面，需要给 `/mcp`、`/oauth/*`、`/.well-known/*` 加「绕过」规则。令牌由 DeverDesk 自己校验，授权页仍留在 Access 后面。

## 它能做什么

| 分组 | 能做的事 |
| --- | --- |
| 随手记 | 一次建多个任务；记收入和支出（带外部单号的会跳过重复）；补记投入时间；开始和停止计时；例行打卡；写周回顾笔记 |
| 查情况 | 今天、这周、全部副业、某个副业的详情；任意时间段的统计；周回顾；关键词搜索；自由查询 |
| 排时间 | 批量改任务；把任务排进某天的空档；按每天能拿出的时间分到一周；挪日子；管副业、里程碑和例行；删除记录 |

可以这样对它说：

- 「看看我今天还剩什么没做。」
- 「这个月哪个副业的时薪最高？」
- 「记一笔：模板商城收入 200。」
- 「把没排日子的任务排进今天的空档。」

## 每一步都留底，随时撤销

AI 的每次改动都会留底。点窗口栏的星星图标打开「AI 动态」，在里面采纳或拒绝提议、撤销改动；AI 建的记录前面也带这个图标。删除，或者一次改超过十条，会先给你看预览，确认后才生效。日期和时间按作息设置里的时区计算，第一次登录时浏览器会自动填上。

## 顺带：让写代码的时间自己记下来

如果你用 Claude Code 或 Codex 写代码，还可以装一个本机记录器，把写代码的时间和任务自动记进对应的副业。时间只在你在场时计算，同时开几个窗口会平分，总数不会超过真实流逝的时间；一次提交算完成一件事；只有绑定了副业的文件夹才会上传，其余内容留在你自己的电脑上。安装方法见仓库 README 的[「自动记录编程时间」](https://github.com/evepupil/DeverDesk/blob/main/README.zh-CN.md#自动记录编程时间)。
